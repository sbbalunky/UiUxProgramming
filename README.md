# Game of the Best - 게임 추천 받기

## 사용자와 목표
- 사용자: 새로운 게임을 해보고 싶은 사람
- 목표: 원하는 게임을 추천 받고 플레이한 후 평가를 남긴다.

## 사용자의 흐름
1. 게임의 소개 방식을 확인한다.
2. 원하는 게임을 선택하고, 그 게임에 대한 정보를 상세히 확인한다.
3. 게임을 즐기는 방법을 확인하고 직접 플레이 하러 간다.
4. 플레이 후에 홈페이지에 자신만의 간단 후기를 남기고 저장한다.
5. 더 자세한 후기를 남기려면 자세한 후기 기록하기 버튼을 눌러 기록한다.

## 인터랙션 시나리오
### 게임 소개
- 행동, 이벤트: 기본적으로 게임 제목 탭을 바로 확인 가능하며, 한 게임에 대한 원하는 정보를 클릭하여 확인한다.
- 반응, 다음 상태: 확인하면 다른 탭을 눌러 그 탭에 대한 정보를 확인한다.

### 플레이 후기
1. 추천이 도움이 되었는가?
- 행동, 이벤트: 추천이 도움이 되었다면 버튼을 누른다.
- 조건: 한 번 누르면 활성화, 다시 누르면 비활성화 된다.
- 반응, 다음 상태: 버튼을 누르면 버튼 색이 분홍색으로 변하며 문구가 "마음에 들어요"로 변경된다. 다시 누를 경우에는 색이 파란색으로 변경되며 문구 또한 "마음에 들지 않아요"로 변경된다.
2. 간단 후기
- 행동, 이벤트: 자신이 남기고 싶은 간단한 후기를 15자 남기고 저장한다.
- 조건: 15자까지만 남겼는가? 1자도 적지 않았는가?
- 반응, 다음 상태: 비어있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다. 값이 있으면 저장하고 평가로 이동한다.
3. 평가하기
- 행동, 이벤트: 사용자가 내린 평가를 체크한다.
- 조건: 평가를 선택했는가? 한가지만 선택을 했는가?
- 반응, 다음 상태: 평가를 선택하고 "기록하기" 버튼을 누르면 "이번 게임은 재밌으셨나요?" 문구가 "의견 감사합니다."로 변경된다. 
"기록하기" 버튼을 누르면 "기록 완료"로 문구가 변경되고 색 또한 초록색으로 변경된다.

### 더 자세한 후기 작성하기
0. 더 자세한 후기 작성하기
- 행동, 이벤트: 더 자세한 후기 작성하기 버튼을 누른다.
- 반응, 다음 상태: 숨겨졌던 후기 작성칸이 새로 등장한다.
1. 이번 게임은 어떠셨나요?
- 행동, 이벤트: 자신만의 후기를 작성하고 기록하기를 누른다.
- 조건: 후기를 입력했는가?
-반응, 다음 상태: 후기를 입력하고 기록하기를 누르면 다음 단계로 넘어간다.
2. 당신의 점수를 매겨주세요.
- 행동, 이벤트: 자신에게 맞는 별점을 누르고 다음 단계로 넘어간다.
- 조건: 별점을 눌렀는가?
- 반응, 다음 상태: 별점을 누르면 별점만큼 별에 노란색이 들어오며, 다른 점수를 누르면 그 점수로 다시 반영된다. 다음 단계를 누르면 다음 단계로 넘어간다.
3. 다른 사람에게 이 게임을 추천하고 싶으신가요?
- 행동, 이벤트: 비추천해요, 추천할래요 버튼중에 하나를 누른다.
- 반응, 다음 상태: 다음 단계로 넘어간다.
4. 기록이 잘 되었는지 확인해주세요.
- 행동, 이벤트: 자신이 남긴 후기가 잘 적혀있는지 확인 가능하며 수정하기, 기록하기 버튼을 누른다.
- 반응, 다음 상태: 수정하기를 누를경우 첫번째 화면으로 돌아가며, 기록하기를 누르면 기록완료 팝업창이 뜬다.

### 모바일 화면 확인
- 360 / 768 / 1100px 오류 없음 확인 완료

# 8주차 새로이 추가한 기능

## 게임 즐겨찾기
- 게임 즐겨찾기 버튼이 추가되고 즐겨찾기한 게임의 목록을 확인 가능합니다.
- 홈페이지를 새로고침하여도 즐겨찾기한 목록은 사라지지 않습니다.

### 인터렉션 시나리오
1. 행동, 이벤트: 게임 제목 밑 부분에 즐겨찾기 버튼을 누른다.
2. 반응 다음 상태: 즐겨찾기 버튼을 누르면 즐겨찾기 완료로 문구가 변경되며 내 즐겨찾기에 즐겨찾기한 게임을 확인할 수 있다. 다시 즐겨찾기 버튼을 누를경우 즐겨찾기가 취소되며, 목록에서도 지워진다.

## 모바일 화면 확인
- 360 / 768 / 1100px 오류 없음 확인 완료
